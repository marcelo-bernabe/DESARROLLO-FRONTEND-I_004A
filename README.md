# Tienda de Videojuegos – Semana 6 (PFY2201)

eCommerce simple con **Bootstrap 5** y **JavaScript** (eventos click/submit, manipulación del DOM y Fetch API).

## Estructura
- `index.html`
- `assets/css/style.css`
- `assets/js/app.js`
- `assets/img/`
- `assets/data/productos.json` (datos cargados con Fetch)

## Funcionalidades
- Navbar responsiva con categorías (Todos, PlayStation, Xbox, Nintendo).
- Productos cargados con `fetch` desde JSON; mensaje amigable si falla.
- Botón "Agregar al carrito" (click) con resumen y total.
- Búsqueda (submit).

## Ejecutar
Usar un servidor local (p. ej. extensión Live Server), ya que `fetch` no funciona con `file://`.
